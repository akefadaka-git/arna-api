# የዓርና የአማርኛ ሰነድ ቁጥር አሰጣጥ መስፈርት

**ስሪት፦** 1.0  
**ሁኔታ፦** የባለቤት የንድፍ ውሳኔ በሰነድ የተመዘገበ፤ የሶፍትዌር ትግበራ እንዳለ ማስረጃ አይደለም።  
**ቋንቋ፦** አማርኛ፤ የቴክኒክ መለያዎች ብቻ በእንግሊዝኛ ተጠብቀዋል።

## 1. ዓላማና ወሰን

ይህ መስፈርት በዓርና ውስጥ በይፋ ለሚወጡ ሰነዶች የመለያ ቁጥር ቅርጸት፣ የኮድ ትርጉም፣ የቆጣሪ ወሰን፣ የኢትዮጵያ ዓመት አወሳሰድና የቁጥር ቋሚነት ይወስናል። ይህ የዓርና የውስጥ መስፈርት ነው፤ በኢትዮጵያ መንግሥት የተደነገገ የቁጥር ቅርጸት ነው ብሎ አያቀርብም።

BB በትክክል ሁለት የቁጥር አሃዞች አሉት።

- አቅሙ 9 ቅርንጫፎች × 9 መምሪያዎች በእያንዳንዱ ቅርንጫፍ ነው።
- ከአቅሙ በላይ ለመሄድ የባለቤት የተለየ ፈቃድና የመስፈርት ስሪት ለውጥ ያስፈልጋል።

## 4. የTT ኮድ ትርጉም

TT በትክክል ሁለት አሃዞች ያሉት የተቆጣጠረ የሰነድ ዓይነት ኮድ ነው። ኮዱ በDocuments የሚቆጣጠረው ዝርዝር ውስጥ ይመደባል። ዝርዝሩ የአማርኛ ስም፣ ትርጉም፣ የሰነድ አቅጣጫ፣ አስፈላጊ መረጃዎች፣ ሥልጣን፣ ምስጢራዊነትና የማቆያ ምድብ ይይዛል።

በምሳሌው ያለው `03` ለማብራሪያ ብቻ ነው፤ የተወሰነ የሰነድ ዓይነት ኮድ እንደሆነ አልጸደቀም። የተጠቀመ ኮድ አይቀየርም፣ ለሌላ ዓይነትም አይመደብም።
